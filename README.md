# أُفُق — مساعد معرفي محلي

نسخة أولية عربية تعمل بدون أي API أو نموذج ذكاء اصطناعي خارجي.

## التشغيل

```bash
cd /home/ubuntu/earthmind-local
python3 -m http.server 4173 --bind 0.0.0.0
```

ثم افتح `http://localhost:4173`.

## ما الذي يعمل؟

- واجهة محادثة عربية RTL متجاوبة.
- بحث مطابق للكلمات داخل قاعدة معرفة محلية في `app.js`.
- أزرار أسئلة جاهزة وسجل محادثة في الذاكرة.
- إدخال صوتي عبر Web Speech API في Chrome/Edge عند توفره.
- قراءة صوتية مفعّلة عبر `speechSynthesis` دون خدمة خارجية من زر القراءة بجانب كل رد.

## حدود النسخة

لا يمكن لتطبيق بلا نموذج لغوي أو مصادر بيانات أن يعرف كل معلومات العالم أو ينافس ChatGPT معرفيًا. هذه النسخة صممت كأساس صادق قابل للتوسعة: أضف عناصر إلى مصفوفة `knowledge`، أو اربط لاحقًا بمحرك بحث/نموذج محلي إذا تغيّر القيد.
